# 📅 Awesome AI4AI Weekly News Archive

A permanent record of the repository's human-curated weekly papers, releases, blogs, and research news. Citation rankings refresh separately in the live README.

- [2026-08-14](2026-08-14.md)

To publish a new edition, update `data/weekly_picks.json`, then run:

```bash
python scripts/archive_weekly.py
python scripts/build_readme.py
```
